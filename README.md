# CyBlack Internship Assessment

## Overview

This repository contains my submission for the CyBlack September 2026 Internship practical assessment.

The assessment is divided into two parts:

1. Malware Investigation using Threat Intelligence
2. Passive Security Assessment of a Public Web Application

---

## Objectives

- Investigate a SHA-256 malware hash.
- Determine malware family and capabilities.
- Document Indicators of Compromise (IOCs).
- Map attacker behavior to the MITRE ATT&CK framework.
- Create detection opportunities using YARA and Sigma.
- Perform passive reconnaissance on a public website.
- Produce a professional security assessment report.
